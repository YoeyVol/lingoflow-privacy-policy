Verlo privacy policy

Updated October 11, 2026. Verlo was previously named LingoFlow.

Input text

Verlo reads the focused web input to provide a translation after typing pauses. It sends that text to the provider selected in preferences: MyMemory by default, Google Cloud Translation, Microsoft Azure AI Translator, or your custom HTTPS LibreTranslate-compatible endpoint. The selected provider processes the text under its own terms and privacy policy. The extension does not collect unrelated page text or build browsing profiles.

Preferences and credentials

Language, shortcut, window position, provider preferences and API keys are stored in local extension storage. A provider key is sent to that provider when its translation service is used. Firefox requires optional credential transmission consent; custom endpoints require host permission.

Logs and tracking

The developer does not operate a translation server and does not receive your translation text, preferences, API keys or browsing history. The extension has no advertising or analytics. Your chosen provider may process requests and logs under its own policies.

Your choices

You can change providers, clear provider keys, dismiss the translation window, or disable or uninstall the extension. Confirm that you are comfortable sending input text to your selected provider before using it.

Contact

Support and privacy requests: contact the developer through GitHub Issues.
